# YBX Reader — интерактивная HTML-визуализация

Основано на **существующем** комплекте `~/Projects/YBX/artifacts/ybx-screen-plans-20261028/`, а не на новом несогласованном дизайне.

## Запуск

Откройте `index.html` в Chrome или Safari. Интернет не нужен: все изображения и демонстрационный QR находятся в `assets/`.

Для просмотра с телефона в той же сети можно запустить локальный HTTP-сервер непосредственно из этой папки:
```sh
python3 -m http.server 8767 --bind 0.0.0.0
```
Адрес: `http://<LAN-IP-Mac>:8767/`. **Не публикуйте этот сервер в Интернете**.

## Что реализовано

- 10 экранов, соответствующих эталонам `01-home.png` … `10-day.png`.
- Интерактивные HTML-версии `06-sources`, `07-pair`, `08-settings`, остальные 7 пока отображаются исходными PNG.
- Переключение размеров X3/X4 480×800 и X4 Pro 528×792, портретной/альбомной ориентаций.
- Состояния: 2/3 источника, пустой каталог, нет привязки, истёк/отозван токен, проблема провайдера, нет сети, подтверждённый/отклонённый вход и истёкший QR.
- Кнопки, демонстрационные диалоги, ссылки на экраны, сопоставление с исходным PNG рядом.
- Сценарии никакие реальные API/токены/книги не запрашивают и не меняют.

## Важные ограничения

- **Это не эмулятор FreeInk.** CSS шрифты, контраст и размеры ещё требуют сверки с настоящими скриншотами X3/X4/X4 Pro.
- Все данные демонстрационные. Часы, книги, коды и статистика — примеры.
- QR кодируется только для общеизвестной ссылки `https://my.ybx.app/pair`; `ABCD 1234` не является реальным кодом.
- «Управление» открывает лишь демонстрационное окно; реальные подключения провайдеров требуют веб-кабинета.
- Действия «обновить» и «новый код» имитируются, без сетевых запросов.

## Проверки

JavaScript проверен через `node --check`; браузерные сценарии Playwright (Chrome) для 10 экранов, 9 пунктов настроек, QR, поворотов, модального окна и отсутствия JS-ошибок пройдены 29.10.2026.
